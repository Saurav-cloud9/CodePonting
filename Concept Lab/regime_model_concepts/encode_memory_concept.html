What is lag-1?

Every day, the model needs an input to make a prediction. That input is yesterday's return — shifted by 1 bar.

In code: lag_1[i] = return[i-1]

Why? Because today's return isn't known yet when you're placing the trade. You can only use what already happened.

What is the hidden state?

A single day's return is too noisy to trust. The rolling-40 mean smooths out 40 days of lag-1 returns into one number — the regime temperature.

In code: rolling(40).mean()

When it's positive: recent momentum is up → model leans long. When negative: market has been falling → model leans short (or stays out).

The hidden state doesn't directly set the signal — it informs w and b during training. When the model is retrained on a sliding window, it absorbs the current regime automatically.
