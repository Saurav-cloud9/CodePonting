# Your Learning Roadmap: 6 Key Pointers

## 1. CodeCombat - Python Starting Point
* **Why:** Gamified basics (loops, if/else) like AoE AI tweaks.
* **Action:** Dive into Backwoods Forest/Sarven Desert levels (e.g., Backwoods Buddy for pet patterns, Sarven Shepherd for patrols).
* **Timeline:** Weeks 1-3; 1-2h/day, 3-4d/week.
* **Link:** [codecombat.com](https://codecombat.com)

## 2. AI HackStack - Automation/ML Intro
* **Why:** Prompt-build/test bots in arenas—mirrors RTS pattern recognition, early ML taste.
* **Action:** Unlock after 5-10 CodeCombat levels; experiment with "scout/rush" bots.
* **Timeline:** Weeks 4-6; tease stock patterns as "enemy waves."
* **Link:** [codecombat.com/hackstack](https://codecombat.com/hackstack)

## 3. Stock Trading - Apply Automation/ML Later
* **Why:** Use learned patterns for predictor bots (e.g., price trends like enemy builds).
* **Action:** In VS Code, prototype with pandas/scikit-learn on mock data; QuantConnect for sims.
* **Timeline:** Weeks 7+; start simple buy/sell rules.
* **Link:** [quantconnect.com](https://quantconnect.com)

## 4. Core (Epic Games) - Game Scripting Fun
* **Why:** Lua scripting for user worlds—RTS modding vibes, creative ML breaks.
* **Action:** Build simple AI scenarios post-Python.
* **Timeline:** Parallel from Week 7; low priority for fun.
* **Link:** [coregame.com](https://coregame.com)

## 5. VS Code - Dev Hub
* **Why:** Export/tweak projects; install extensions for Python/ML (e.g., Jupyter).
* **Action:** Setup after HackStack; use for stock/Godot prototypes.
* **Timeline:** Weeks 7+ core tool.
* **Link:** [code.visualstudio.com](https://code.visualstudio.com)

## 6. Godot - RTS Prototypes
* **Why:** GDScript (Python-like) for AoE-style games; add ML for smart units.
* **Action:** Build basic AI paths/enemy prediction; leverage your prior tinkering.
* **Timeline:** Parallel from Week 7; after VS Code setup.
* **Link:** [godotengine.org](https://godotengine.org)
