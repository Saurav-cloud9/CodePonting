## 📊 STRATEGY OVERVIEW

### What is a Bull Put Spread?

**Simple Definition:**
- You sell a PUT option (collect premium)
- You buy a PUT option further below (limit risk)
- Net result: Credit in your account upfront
- Goal: Both options expire worthless, you keep the credit

**Example Setup:**
```
NIFTY: 23,500
Expiry: Thursday (weekly)

SELL: 23,200 PE @ ₹85 → Collect ₹4,250
BUY:  23,000 PE @ ₹45 → Pay ₹2,250
────────────────────────────────────
NET CREDIT: ₹2,000 in pocket ✅
MARGIN BLOCKED: ~₹50,000

Your bet: NIFTY stays above 23,200 by Thursday
Probability: 75-80% (it's 300 points below!)
```

**Possible Outcomes:**

| Scenario | NIFTY Level | Result | Probability |
|----------|-------------|--------|-------------|
| Win | > 23,200 | Keep ₹2,000 profit | 75-80% |
| Break-even | 23,000-23,200 | ₹0 to -₹2,000 | 15-20% |
| Max Loss | < 23,000 | -₹8,000 (after credit) | 5% |

```
Formula for conservative strikes:

Buy Strike = Sell Strike - 200 points

Example:
NIFTY: 23,500
Sell: 23,200 PE
Buy: 23,000 PE

```
Look at options chain:

If < ₹1,800 → Adjust strikes or skip

## ⚠️ COMMON MISTAKES TO AVOID

### Execution Errors:

**❌ Mistake #1: Buying instead of selling**
```
Wrong: BUY 23,200 PE, SELL 23,000 PE (this is a debit spread!)
Right: SELL 23,200 PE, BUY 23,000 PE (credit spread ✅)
```

**❌ Mistake #2: Not executing both legs**
```
Wrong: Only sell option (naked selling = unlimited risk!)
Right: Always execute BOTH sell AND buy together
```

**❌ Mistake #3: Wrong expiry selection**
```
Wrong: Selecting monthly expiry (too far, less premium decay)
Right: Weekly expiry every Thursday (faster theta decay)
```

**❌ Mistake #4: Strikes too close to spot**
```
Wrong: NIFTY 23,500, Sell 23,400 PE (only 100 pts away)
Right: NIFTY 23,500, Sell 23,200 PE (300 pts buffer)
```

## 📚 EDUCATIONAL RESOURCES

### Must-Learn Concepts:

**1. Option Greeks (Simplified):**
```
Delta: How much option moves with underlying
  → OTM options (your sold strikes) = Low delta ✅
  → Means: Slow movement, safe zone
  
Theta: Time decay (your friend!)
  → Every day, options lose value
  → Sold options = You profit from decay ✅
  
Gamma: Rate of delta change
  → OTM options = Low gamma ✅
  → Means: Delta won't suddenly spike
  
Vega: Volatility sensitivity
  → OTM options = Lower vega
  → Less affected by vol changes
```

**2. Implied Volatility (IV):**
```
High IV = Options expensive = Good for selling! ✅
Low IV = Options cheap = Less premium collected

Check VIX before setup:
  VIX > 20: Great time to sell (high premiums)
  VIX < 12: Mediocre time (low premiums)
```

**3. Probability of Profit:**
```
Delta of sold option ≈ Probability of expiring ITM

Example:
Sell 23,200 PE, Delta = 0.25
Probability it expires ITM = 25%
Probability it expires OTM = 75% ✅

Always aim for delta < 0.30 on sold strikes
```
