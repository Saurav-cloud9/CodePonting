## 1. Strategy definition

| Item | Detail |
|---|---|
| **Side** | SHORT |
| **Signal (v1 clean-touch)** | Single bar where `high >= MA20` AND `open < MA20` AND `close < MA20` |
| **Entry** | Open of next bar (`i+1`), same trading day; skipped if `hour[i+1] >= 15` or date changes |
| **Signal hour filter** | Signal bar must have `hour < 15` |
| **SL** | `entry + SL_MULT × ATR14` |
| **TGT** | `entry - TGT_MULT × ATR14` |
| **Exit priority** | (1) Date change → prior close · (2) `hour >= 15` → bar open · (3) SL hit · (4) TGT hit |
| **Position guard** | Single-pass; resume at `i = k + 1` after each trade |
| **Universe** | 30 DS3 stocks, 5-min bars, 2015–2025 |
| **Data path** | `data/historical/intraday_5min_DS3/*.parquet` |

### Zerodha charge model (per trade, qty = 1, SHORT)

```
brok  = min(0.0003 × entry, 20) + min(0.0003 × exit, 20)
stt   = entry × 0.00025                    # sell (entry) side
txn   = (entry + exit) × 0.0000307
sebi  = (entry + exit) × 0.000001
stamp = exit × 0.000003                    # buy (exit) side
gst   = 0.18 × (brok + txn + sebi)
total = brok + stt + txn + sebi + stamp + gst
zpnl  = raw_pnl - total
```

### Primary metrics

- **ZPF** = sum(winning zpnl) / abs(sum(losing zpnl)) — target **ZPF > 1.0**
- **ZSh(D)** = (mean(daily_zpnl) / std(daily_zpnl)) × √252 — target **ZSh(D) > 0**
- **PF / Sh(D)** = raw (pre-charge) reference only

### Sweep grid (90 combos)

```
SL_MULT  : 1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0, 5.5, 6.0
TGT_MULT : 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0, 5.5, 6.0
```

## 8. Observations

1. **High trade count** — 81k–149k trades over 11 years (very dense signal). Charges dominate because edge per trade is tiny.
2. **Raw edge exists but is thin** — PF ~1.09–1.14; not enough to cover Zerodha costs at qty=1.
3. **Wider stops/targets help after charges** — fewer trades, slightly better ZPF; still max ZPF 0.831.
4. **ZSh(D) always negative** — even best combo has daily Sharpe after charges of -2.1 annualised.
5. **Year stability is weak** — 2023 collapses (raw PF ~1.0); several mid-2010s years are only 🟡 on ZPF.
6. **vs viability rules** — fails both ZPF > 1.0 and ZSh(D) > 0; also triggers rule-out (best ZPF < 0.85).
