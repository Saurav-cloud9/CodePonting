# 📊 Excel Navigation Guide - MA Bounce Backtest Results

## 🎯 How to Switch Between Sheets

Your Excel files now have **3 EASY ways** to navigate:

---

## ✅ Method 1: Table of Contents (Recommended)

**The first sheet is now a "Table of Contents" (📑 TOC)**

1. **Open the Excel file**
2. **You'll see the TOC sheet first** with clickable blue links:
   - 🔗 Summary Sheet
   - 🔗 Winners Sheet
   - 🔗 Losers Sheet
   - 🔗 Pattern Analysis

3. **Click any blue link** to jump directly to that sheet

---

## ✅ Method 2: "Back to TOC" Links

**Every data sheet has a "Back to TOC" link at the very top**

1. When viewing any sheet (Summary, Winners, Losers, Pattern Analysis)
2. Look at **Row 1, Column A**
3. Click: **⬅️ Back to Table of Contents**
4. You'll jump back to the TOC sheet

---

## ✅ Method 3: Sheet Tabs (Traditional)

**Use Excel's built-in sheet tabs at the bottom**

1. Look at the **bottom of the Excel window**
2. You'll see tabs for each sheet:
   - 📑 TOC
   - Summary
   - Winners
   - Losers
   - Pattern Analysis

3. **Click any tab** to switch to that sheet
4. **Use arrow buttons** (◀ ▶) if you have many sheets

## 💡 Pro Tips

### Keyboard Shortcuts (Excel)
- `Ctrl + Page Down` → Move to next sheet
- `Ctrl + Page Up` → Move to previous sheet
- `Ctrl + Home` → Go to cell A1 of current sheet

### Quick Navigation
1. **Start at TOC** - Get overview
2. **Check Winners** - See what worked
3. **Compare Losers** - Understand failures
4. **Study Pattern Analysis** - Find trends

### Excel Features
- **Freeze Panes**: View menu → Freeze Top Row (keeps headers visible)
- **Filter**: Click column header → Filter → Sort/Filter data
- **Search**: `Ctrl + F` → Find specific stocks

## 🔧 Troubleshooting

### Links not working?
- Make sure you're clicking the **blue underlined text**
- The link should say "🔗" or "⬅️"

### Can't see sheet tabs?
- Look at the **very bottom of Excel window**
- If hidden: Right-click any visible area → "Unhide Sheet"

### Want to go to a specific cell?
- Press `Ctrl + G` → Type cell reference (e.g., "A1") → Enter
